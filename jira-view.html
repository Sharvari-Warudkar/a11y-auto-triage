A11Y-001 · product-listing.html
Insufficient Color Contrast on Product Price
Minor
WCAG Criterion
1.4.3 — Contrast (Minimum) Impact: Serious
Affected Users
Low vision users Color vision deficiency Older users
Steps to Reproduce
  1. Open the product listing page
  2. Navigate to the product cards
  3. Observe the text color and background color of the product prices
Expected vs Actual
Expected: Text contrast ratio of at least 4.5:1 against background
Actual: Product prices have contrast ratio of 2.32:1 (fails 4.5:1 minimum)
Suggested Fix
Change .product-price color from #aaaaaa to #595959 or darker to achieve 4.5:1+ contrast ratio on white background
Element Selector
.product-card > p.product-price

A11Y-002 · product-listing.html
Missing Image Alt Text on Product Images
Critical
WCAG Criterion
1.1.1 — Non-text Content Impact: Critical
Affected Users
Blind users Low vision users Cognitive disabilities Slow connections
Steps to Reproduce
  1. Load the product listing page
  2. Inspect images with src attributes 'shoe-red.jpg' and 'shoe-green.jpg'
  3. Verify that images do not have alt attributes
Expected vs Actual
Expected: All non-text content has a text alternative serving equivalent purpose
Actual: Product images lack alt attributes — screen readers announce only the filename
Suggested Fix
<img src="shoe-red.jpg" alt="Red running shoe, side view" width="200" height="200">
Element Selector
img[src$="shoe-red.jpg"], img[src$="shoe-green.jpg"]

A11Y-003 · cart.html
Remove Button Has No Accessible Name
Major
WCAG Criterion
4.1.2 — Name, Role, Value Impact: Serious
Affected Users
Screen reader users Voice control users Switch access users
Steps to Reproduce
  1. Navigate to the shopping cart page
  2. Tab to the remove (×) button next to any item
  3. Listen with screen reader — announces "times" or "button" with no context
Expected vs Actual
Expected: Button has an accessible name describing its purpose
Actual: Button contains only "×" character — screen readers cannot convey the action
Suggested Fix
<button class="remove-btn" aria-label="Remove Running Shoe - Red from cart">×</button>
Element Selector
button.remove-btn

A11Y-004 · checkout.html
Form Inputs Missing Associated Labels
Major
WCAG Criterion
3.3.2 — Labels or Instructions Impact: Serious
Affected Users
Screen reader users Cognitive disabilities Low vision users
Steps to Reproduce
  1. Navigate to the checkout form
  2. Tab through form fields (Full Name, Email, Address, etc.)
  3. Note that screen reader announces only "edit text" with no field purpose
Expected vs Actual
Expected: Each input has a visible, associated label element
Actual: Inputs use only placeholder text — disappears on focus, not programmatically associated
Suggested Fix
<label for="name">Full Name</label> <input type="text" id="name" placeholder="Full Name">
Element Selector
#name, #email, #address, #city, #zip, #card, #expiry, #cvv
