1. Problem Statement

Domain: E-commerce — accessibility compliance

User: QA engineers responsible for accessibility testing on e-commerce platforms

Problem: Manual WCAG 2.1 AA audits take ~45 minutes per page, produce inconsistent bug reports lacking remediation guidance, and violations recur because there's no deduplication.

Definition of Success: Reduce per-page triage to <5 minutes, with ≥85% correct WCAG criterion citations and code-level fix suggestions.

2. Solution Architecture

Target URL → Playwright + axe-core (scan) → Deduplication → Keyword/TF-IDF Retrieval (WCAG docs) → Groq/Llama 3.3 (generate) → Structured JSON Bug Reports

ComponentTechnologyRationale
ScannerPlaywright + @axe-core/playwrightIndustry standard, TypeScript native
RAG RetrievalKeyword/TF-IDF matchingZero infrastructure for 9-doc corpus
LLM GenerationGroq (Llama 3.3 70B Versatile)Free tier, fast, structured output
LanguageTypeScript (strict mode)Type safety, maintainability

3. Data Provenance

Source: 4 synthetic HTML fixtures (product-listing, product-detail, cart, checkout) with deliberately injected WCAG AA violations. Authored by the submitter based on real violation patterns in production e-commerce sites.

WCAG Knowledge Base: 9 WCAG 2.1 success criteria (Level A and AA) manually curated as markdown.

What it does NOT represent: Dynamic SPA rendering, third-party widgets, mobile touch-targets, violations requiring user interaction.

Sensitive data: None. All fixtures are original synthetic content.

8. RAG Pipeline

StageImplementation
LoadRead 9 WCAG markdown files from data/wcag/
ChunkOne chunk per success criterion (title + requirements + techniques + remediation)
IndexKeyword/TF-IDF frequency maps per document (cosine similarity)
StoreJSON persistence at data/vector-store.json
QueryBuild query from violation ID + help text → top-3 matching criteria

Trade-off: Keyword matching is fast and free but semantically shallow — common words cause irrelevant matches in position 2-3. A vector embedding approach would improve precision but adds API cost and infrastructure.
